# MicroDuck Lab v1.0

## Scope

Version 1.0 establishes a reproducible sim-training foundation on DGX Spark:

- pinned official Pollen Robotics training source;
- isolated, lockfile-driven ARM64 CUDA environment;
- unified-memory and swap safety checks;
- CPU regression suite;
- CUDA/MuJoCo/Warp readiness report;
- required 64-environment PPO smoke run;
- normalizer-aware ONNX contract and CPU inference verification;
- configurable walking-baseline command;
- offline experiment logs retained under `reports/` and upstream `logs/`.

Creating a novel learned trick is intentionally a v1.1 activity. First prove
that the unmodified official pipeline builds, steps, learns, exports, and runs.

## v1.0 release gates

1. `make bootstrap` completes from the pinned lockfile.
2. `make preflight` reports ARM64, CUDA-enabled PyTorch, one GB10, Warp, and MuJoCo.
3. `make test` passes the complete upstream CPU test suite.
4. `make smoke` completes five PPO iterations across 64 environments without NaNs.
5. `make verify-artifact` validates ONNX structure, 61D input, 14D output,
   deployment metadata, finite inference, and 100 CPU MuJoCo steps.
6. The repository contains no credentials, checkpoints, large logs, or generated policies.
7. A clean clone with submodules can repeat gates 1–5.

## Policy qualification

Before an ONNX policy is allowed onto hardware, retain its exact source commit,
task configuration, checkpoint, training metrics, rollout video, and randomized
evaluation results. Check falls, impacts, joint limits, action smoothness,
backlash robustness, and recovery rate—not only total reward.

## Arrival-day sequence

1. Update and verify the factory robot software.
2. Exercise the factory walking/recovery policies in a padded test area.
3. Record real joint, IMU, battery, and command traces.
4. Compare those traces with `scripts/infer_policy.py --save-csv` simulation output.
5. Deploy only an officially exported ONNX policy with rollback available.
6. Start at conservative commands and stop on repeated falls, overheating, or joint-limit contact.
